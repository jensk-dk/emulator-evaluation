# Host Platform Support Specification

## Purpose

Define the operating systems that can host the emulator during development.

## Requirements

### Requirement: Supported development host operating systems

The emulator MUST run on Linux, macOS, and Windows as development/host operating systems.

#### Scenario: Run on Linux

- WHEN a developer launches the emulator on a Linux host
- THEN the emulator runs on that host

#### Scenario: Run on macOS

- WHEN a developer launches the emulator on a macOS host
- THEN the emulator runs on that host

#### Scenario: Run on Windows

- WHEN a developer launches the emulator on a Windows host
- THEN the emulator runs on that host
